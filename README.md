# Deu Pingo

Rede social de relacionamento com cara de Instagram e alma de Orkut.
Tema rosa, logo pinguim, scraps, depoimentos e comunidades.

MVP local: feed + perfil + comunidades. Sem backend. Dados mock.

## Como rodar no VS Code

1. Instale [Node.js LTS](https://nodejs.org)
2. Abra **esta pasta** (`pinguork`) no VS Code
3. No terminal:

```bash
npm install
npm run dev
```

4. Abra http://localhost:3000

## Telas

- `/` feed
- `/perfil/marina` seu perfil
- `/perfil/joao` outro perfil
- `/comunidades`
- `/comunidades/eu-odeio-segunda-feira`
- `/comunidades/00h01-e-a-insonia/topicos/t3`

Botões de Crush, DM e Publicar estão visíveis, mas ainda são mock (não salvam).

## Stack

Next.js + Tailwind + TypeScript
